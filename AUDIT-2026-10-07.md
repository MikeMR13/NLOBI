# Auditoría completa de plataforma — 2026-10-07

## Alcance

- Frontend público, móvil, Reader, Biblioteca, perfiles y equipos.
- Studio, editor, importador, multimedia y administración.
- Supabase: RLS, grants, funciones, triggers, Storage, cron, advisors y logs.
- Vercel: proyecto, deployments, variables y observabilidad disponible.
- CI: Chromium, Firefox y WebKit/Safari smoke.

## Hallazgos corregidos

1. RLS/integridad multi-equipo reforzada para enlaces oficiales, comentarios, reacciones, reportes y actividad pública.
2. Privilegios PostgreSQL web reducidos: sin TRUNCATE/REFERENCES/TRIGGER y sin escrituras anon.
3. Edición de metadatos de novelas alineada con roles editoriales.
4. Creación novela+traducción convertida en RPC transaccional.
5. Inserción directa de novelas bloqueada a usuarios web para evitar obras huérfanas.
6. Funciones administrativas/trigger que llamaban helpers privados corregidas a contexto SECURITY DEFINER con search_path vacío.
7. Studio diferencia roles de consulta (proofreader/collaborator) de roles editoriales.
8. Variables Vercel heredadas NEXT_PUBLIC_* aceptadas por el generador runtime.
9. Compatibilidad CI ampliada a Firefox y WebKit.
10. Importador limitado a 80 MB y ZIPs con máximo 15 000 entradas / 300 MB descomprimidos para mitigar agotamiento de memoria y ZIP bombs.
11. URL de banner endurecida para contexto CSS, evitando cierre de `url(...)` mediante caracteres especiales.

## Verificaciones realizadas

- Supabase security advisor: sin errores; queda una advertencia agrupada por tres RPC `SECURITY DEFINER` públicos. Son intencionales, con `search_path` vacío, `EXECUTE` restringido y comprobación interna de autorización.
- Pruebas RLS transaccionales y reversibles: lectura pública, borradores, aislamiento entre equipos, editor, colaborador y administrador.
- Enlace oficial propio permitido; enlace cruzado bloqueado; verificación admin permitida.
- Logs Supabase del periodo auditado sin errores/fatales encontrados.
- Vercel runtime errors (ventana disponible): sin errores detectados.

## Riesgos operativos pendientes

- Vercel `nlobi` no apareció enlazado a `MikeMR13/NLOBI` en la integración consultada; el último deployment observado usa un SHA anterior a `main`. Los alias `nlobi.vercel.app` y `nlobi-cronica.vercel.app` seguían sirviendo la versión antigua “NLOBI”; el primero no llevaba la CSP actual y el segundo además devolvía `x-robots-tag: noindex`.
- El plan Vercel Hobby limita la retención de runtime logs; la consulta de 24 h no estaba disponible.
- Storage `nlobi-media` es público (intencional para portadas/ilustraciones) y tiene versionado desactivado.
- La base todavía no contiene carga comparable a producción; los avisos de índices no usados no son concluyentes.
- Siguen siendo necesarias pruebas con DOCX/EPUB/PDF japoneses reales y una estrategia formal de backup/restauración.
